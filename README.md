# photomap
Fast, secure and free framework to plot pictures on a map

This is an educational project in order to start learning several technologies:
* HTML + CSS
* JavaScript (jQuery.js and leaflet.js)
* Node.js (probably also backbone.js)
* SQL
* AWS services (API Gateway, Web hosting, Lambda

And several concepts:
* Client-server architectures (MVC, etc.)
* Asynchronous programming concepts (in particular, react programming via event loops etc.)
